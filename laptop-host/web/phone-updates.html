One-time USB setup

Install game app 1.59 or newer once before using automatic Wi-Fi installation. Older apps do not provide the idle check required by this host.

  1. Join this laptop's game Wi-Fi on the phone. Enable Developer options and USB debugging.
  2. Connect USB, unlock the phone, and accept Allow USB debugging? Choose Always allow from this computer.
  3. Select Enroll beside that phone below. Keep USB connected until its enrolled status confirms Wi-Fi access, then unplug it.

Use a trusted game Wi-Fi and do not forward the debugging port through a router. On older Android phones, Wi-Fi debugging usually turns off after a reboot; reconnect USB and enroll again when that happens.
