Event phone setup

Install the updated LAZER GUN RUN app on each phone. Join the laptop’s Recoil Wi-Fi, connect a blaster, and let the laptop assign the player.

On the laptop’s Players page, turn on Event Mode to reserve names, teams, rules, and game controls for the organizer. Turn on Kiosk Mode to keep the game pinned.

Ordinary phones: screen pinning

Confirm Android’s pinning prompt on each phone. Android still allows its system unpin gesture. The laptop shows “screen pinned” so you can distinguish this from a fully locked event phone.

Dedicated event phones: full kiosk lock

Android requires device-owner provisioning for full kiosk lock. Use event-owned phones with no personal accounts or other device administrator. Enabling the app as an ordinary device administrator alone does not grant kiosk authority.

With Android developer options and USB debugging enabled, connect one prepared phone to this computer, approve its debugging prompt, and run:

adb devices
adb shell dpm set-device-owner com.simplecoil.simplecoil/.EventDeviceAdminReceiver

If Android rejects provisioning because the phone is already set up or has accounts, prepare it as a dedicated device before trying again. This app does not erase phones or remove accounts. See Android’s lock task documentation.

Open the game and join the laptop. With Event Mode and Kiosk Mode enabled, a managed phone enters full lock task mode. The laptop reports Phone locked in Kiosk Mode.

Organizer unlock and recovery

To release one phone, clear “Keep this phone pinned” for its player and save. To release everyone, turn off Kiosk Mode or Event Mode and apply. To unlock offline, use the phone’s Organizer unlock button, or Back during play, and enter the organizer PIN from the laptop’s Event Mode settings. Three incorrect PIN attempts pause entry for one minute. Long-press the Organizer unlock button to retry Android’s pinning prompt.

New events use a two-digit organizer PIN. You may choose two to six digits, including leading zeros. Existing longer PINs continue to work until replaced.

Player profiles stay on the laptop. Phone transfers happen in the lobby: connect a replacement, select the saved player, and use “Move to another phone.”
